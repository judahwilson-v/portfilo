# Lake Portfolio 2026

The personal portfolio of Judah Vijai Wilson. An AI-native web surface and creative development build crafted with motion, pressure, and negative space.

## ✨ Highlights
- **Kinetic Interface**: Features continuous scroll loops, fluid typography, and bespoke animations.
- **Micro-Interactions**: Dynamic cursor modes, spatial sound themes, and interactive feedback.
- **Content Delivery**: Displays a curated selection of "pressure points"—from contact-first hospitality sites (`diamond-banquet-hall`) to smart hardware prototypes (`Sense Stick`).

## 🛠 Tech Stack
- Vanilla HTML5 / CSS3 / ES6+ JavaScript
- Custom Motion & Intersection Observers
- Zero-framework, lightweight static delivery

## 🚀 Running Locally
Because this project relies entirely on static assets without a build step, you can run it using any local web server.

```bash
# Using Python:
python3 -m http.server 3000

# Using Node (npx):
npx serve .
```
